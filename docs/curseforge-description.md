# Virtuous Companion

**The official addon for the Virtuous guild on WoW Forever.** Virtuous Companion brings useful guild tools into the game and connects them with the Virtuous website, Discord and desktop companion.

## Guild tools in game

- **Tickets:** Send guild-bank material requests and absence notices, check their status and reply to synced conversations.
- **Raid signups:** View your teams' upcoming raids and sign up with the Main character assigned to each team, even when you are playing an alt.
- **Discord names:** See linked members' Discord server names in the guild roster.
- **Guild ranks:** Authorised officers can review synced rank mismatches and make supported in-game corrections.

Open the **Guild & Communities** window to find the Companion tabs, or type **`/vt`** or **`/virtuous`**.

## Getting started

1. Install **Virtuous Companion** through CurseForge.
2. **Log in to the [Virtuous website](https://virtuous.dk), then download the Windows desktop companion from [virtuous.dk/companion](https://virtuous.dk/companion).** The desktop app is available only on the website after login.
3. Open the desktop app, choose your World of Warcraft folder and connect your Virtuous Discord account.
4. Enable the addon in WoW and use **`/reload`** to load your guild data.

The desktop companion runs quietly in the background and receives automatic updates after you connect Discord. You can change its Windows startup and background settings inside the app.

## How syncing works

When you submit a ticket or change a signup in game, use **`/reload`** or log out so WoW saves the change. The desktop companion sends it to the guild services and prepares incoming data. Use **`/reload`** again to see the latest information. WoW can remain open while the desktop app syncs.

## Requirements

- A supported **WoW Forever** client.
- Membership of the **Virtuous guild Discord**.
- The **Virtuous desktop companion for Windows** for sign-in and syncing.

Visit [virtuous.dk](https://virtuous.dk) for guild information and support. [Addon source code](https://github.com/Warriorcatzz/virtuous-companion-addon).
